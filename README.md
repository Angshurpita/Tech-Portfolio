# Angshurpita Ganguly — 3D Professional Tech Portfolio

A high-performance, 3D interactive tech portfolio engineered with **React 19**, **Three.js**, **Vite**, and **Tailwind CSS**, designed with the **Akashic glacier lite theme aesthetic** (`getakashic.web.app`).

---

## 🌟 Key Highlights & Engineering Features

### 1. 3D WebGL Glacier Atmosphere (`Three.js`)
- **Morphing Crystalline Celestial Orb**: Procedurally deformed icosahedron lattice with an inner physical glass core, undulating with organic mathematical sine waves.
- **Dynamic Physics & Interaction**: Smooth lerp tracking to cursor movement, counter-rotating orbital rings, and a drifting field of 280+ celestial glacier particles.
- **Automatic Optimization**: Intersection observer pauses WebGL rendering when off-screen to preserve battery and GPU resources.

### 2. Akashic Glacier Design System
- **Lite Theme (Preferred)**: Calm, frosted glass aesthetic (`#f5f8ff` glacier blue backdrop, subtle mesh dither, crisp micro-borders, and high-contrast typography).
- **Floating Pill Navigation**: Glassmorphic capsule navbar with dynamic scroll progress indicator, sound toggle, theme switcher, and terminal shortcut.
- **Atmosphere Synthesizer (Web Audio API)**: Zero external audio assets—synthesizes subtle futuristic chimes, key clicks, and celebration tones with an instant mute toggle.

### 3. Interactive Systems Sandbox (Architecture Lab)
Interactive, live state-machine simulators for 4 flagship architectures:
1. **NERV-VIPER**: 3-layer agentic topology (*Directives -> Orchestration -> Execution*) simulating static AST inspection and zero-hallucination patch generation.
2. **PROJECT IRONCLAD**: Hybrid RAG pipeline fusing *BM25 lexical search* and *dense vector embeddings* via *Reciprocal Rank Fusion (RRF)* + *AST citation verification*.
3. **QUANTARA**: Directed graph-theory intelligence engine running *cycle detection*, *fan-out dispersal*, and *mule fan-in aggregation* across 100K+ transaction batches (3rd at Smart India Hackathon).
4. **pyredis-engine**: Zero-dependency from-scratch storage engine simulating raw byte-level *RESP protocol* parsing over *asyncio TCP sockets* and *SkipList* multi-level traversal (128,000+ req/sec).

### 4. Interactive CLI Terminal (`Ctrl+K` or `` ` ``)
Full-featured in-browser terminal emulator:
- Commands: `help`, `bio`, `projects`, `ironclad`, `nerv`, `quantara`, `redis`, `skills`, `metrics`, `contact`, `sudo hire` (with confetti!), `clear`, `exit`.
- Arrow key command history, auto-scrolling, and authentic sound effects.

### 5. Featured Projects & Technical Arsenal
- Filterable project gallery with deep-dive architecture modal drawers and direct GitHub links.
- Searchable skills matrix spanning AI & LLM Systems, Low-Latency Networking, Systems Programming, and Tools.
- Career trajectory featuring **NERV-VIPER** (Founder & Lead Architect), **The Manhattan Project** (ML Intern), **GCECT** (9.72 CGPA, Top 1%), **McKinsey Forward Program**, and **SIH 3rd Position**.

## 🚀 Running Locally

```bash
# 1. Install dependencies
npm install

# 2. Start development server
npm run dev

# 3. Build for production
npm run build

# 4. Preview production build
npm run preview
```

## 📦 Deployment Options

The project builds to standard static files in `dist/` and can be deployed with a single command to:
- **Vercel**: `vercel deploy`
- **Firebase Hosting**: `firebase deploy`
- **GitHub Pages**: `npx gh-pages -d dist`
- **Netlify**: `netlify deploy --prod --dir=dist`
